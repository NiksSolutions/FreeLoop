# Vendor logos

The marks that show what a session runs on (GUI-034) use a vendor's logo only where the vendor's published terms allow a third-party app to show it. Each file here is the vendor's own, unchanged; the window draws it as an image, in the variant the vendor made for a light or a dark background, on the page's own background. Every other provider and agent keeps two letters, or a picture the user chooses in Settings. Why the others are left out is in `docs/RISKS.md` (L-03). Checked 2026-11-27.
