The first beta of Freeloop: a desktop app for macOS, Windows and Linux that runs coding agents, its own and Claude Code, Codex CLI, Copilot CLI, Gemini CLI and OpenCode, under your permission policy and with one bill across all of them. It is a first beta for a few testers; please report what breaks. Settings → Data → **Copy a report** puts what an issue needs on the clipboard, and nothing is sent anywhere.

**Before you install.** The files are not signed for Apple or Microsoft (OQ-057 in `docs/OPEN_QUESTIONS.md`), so your system warns about them the first time. The checksums are signed with the project's own key (`SHA256SUMS.sig`). Check the download first:

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing   # macOS
sha256sum -c SHA256SUMS --ignore-missing       # Linux, or Git Bash on Windows
```

- **macOS:** `Freeloop.dmg`. Open it and drag Freeloop to Applications. macOS blocks it the first time: try to open it, then choose **Open Anyway** in System Settings, under Privacy & Security. The Keychain asks again after each update, because the signature changes with every build. Needs a Mac with Apple Silicon (M1 or later) and macOS 14 or later; there is no Intel build.
- **Windows:** `Freeloop-0.1.0-beta.1-windows-<arch>-setup.exe` installs Freeloop for your user alone, without administrator rights; the `-portable.zip` runs from any folder. Take `amd64` for most PCs and `arm64` for ARM ones. If SmartScreen stops it, choose **More info**, then **Run anyway**. Needs Windows 10 version 1809 or later with the Microsoft Edge WebView2 Runtime, which Windows 11 includes and the installer offers otherwise, and [Git for Windows](https://git-scm.com).
- **Linux:** `Freeloop-0.1.0-beta.1-linux-<arch>.AppImage`, which carries its own WebKitGTK, or the `.deb` for Debian and Ubuntu; `amd64` or `arm64`. Saving a key needs a running Secret Service, such as GNOME Keyring or KWallet.

**What is in this release.** Besides the packages: a bill of materials for each (`*.sbom.cdx.json`), the third-party notices, and `BUILDINFO` files naming the tools each was built with, so you can rebuild it and compare (`docs/DEVELOPING.md`, "Making a release"); `APP-FILES.sha256` with every file in the Mac app; and `SHA256SUMS` over all of them, with its signature.

**Known gaps in this beta.**
- The Windows and Linux builds are new and have not yet been run on a Windows or Linux desktop; expect rough edges there. Windows has no sandbox yet; use a Docker environment there.
- The update check never offers a pre-release: get the next beta from the Releases page.
- Gemini CLI reports no model, so its usage has no price unless its profile names the model it runs on; OpenCode reports no tokens, which the app says rather than showing $0.
- goose runs whatever version you installed: unlike the other agents, the app does not fetch it at a version of its own choosing. The checks with real agents (`make verify-agents`) run goose 1.57.0, pinned by its checksum in `scripts/agents.sha256`, and only on Apple Silicon Macs; other versions, and goose on Windows and Linux, are untested. This beta's own checks at its tag ran before that pin and skipped goose; it has passed them since (2026-11-22).
- What each requirement was checked with, and what still waits for real use, is in `docs/CHECKLIST-0.1.md`.
