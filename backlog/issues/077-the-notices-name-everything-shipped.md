## What
Found in the review of 2026-11-23 (SEC-012). `internal/sbom/notices.go:41-47, 70-72` only names a package with no licence file on stderr and carries on, and never considers Go's own runtime and standard library; `@wailsio/runtime` (MIT, bundled) ships no licence file and is missing from the notices; the AppImage (`build/linux/Taskfile.yml:93-110`) carries no notices file; Linux builds carry no commit (`build/linux/package.sh:15`).

## Acceptance
- A package with no licence file fails the build unless an in-repository fallback text exists for it (add one for `@wailsio/runtime` from its repository's MIT licence, stating where it came from).
- Go's BSD licence is in the notices. The AppImage contains `THIRD_PARTY_NOTICES.txt`. The Linux container build gets the commit passed in.
- The SBOM or the notices say that the AppImage bundles the system's GTK and WebKitGTK and the Windows installer Microsoft's WebView2 bootstrapper.
- Tests in `internal/sbom`. Do not run the packaging itself.
